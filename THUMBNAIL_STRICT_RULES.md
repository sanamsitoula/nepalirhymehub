# Nepali Rhyme Hub — Strict Thumbnail Attraction & A/B Testing Standard (2026)
## The 7 Golden Rules for Irresistible Children's & Family Thumbnails

---

## 1. Executive Directive: The Psychology of High-CTR "Attraction"

On YouTube, TikTok, Facebook, and Instagram, **over 85% of traffic comes from mobile screens where a thumbnail is seen for only 0.4 seconds at a size of ~120 pixels wide.** 
If a thumbnail does not immediately evoke emotional delight, curiosity, and high-contrast visual clarity, parents and children scroll past.

This document establishes the **STRICT THUMBNAIL RULE** enforced across all projects in the `nepalirhymehub` universe. Every single song must generate **2 A/B Testing Landscape Thumbnails (16:9)** and **2 Vertical Cover Thumbnails (9:16)** before any distribution.

---

## 2. The 7 Golden Rules of Attraction

```
+-----------------------------------------------------------------------------------+
| [BADGE: Saffron / Red Pill]                                                       |
|                                                                                   |
|  2-3 WORD PUNCHY HOOK                [3D CHARACTER FACE & EYES]                   |
|  (Nirmala UI Bold, 115-140pt)        - Occupies 35% to 50% of the frame           |
|  White/Gold with Heavy 12px          - Big expressive dark eyes looking at camera |
|  Night-Blue Shadow & Glow            - Mouth singing or gasping in joy            |
|                                      - Warm golden rim lighting & rosy cheeks     |
|                                                                                   |
|                                                                                   |
|                                            +----------------------------------+   |
|                                            | [EXCLUSION ZONE: BOTTOM-RIGHT]   |   |
|                                            | YouTube Duration Badge (e.g.5:15)|   |
|                                            | ZERO text, ZERO faces here!      |   |
+-----------------------------------------------------------------------------------+
```

### Rule 1: The "Big Eyes & Emotion Anchor" (Eye Contact & Delight)
- **Visual Centerpiece**: The lead character's face (Aarya, Aarav, Tenzing, Rhea, Bikash, or Puntu) must occupy **35% to 50% of the frame**.
- **The "YouTube Gaze"**: Characters must make direct or near-direct eye contact with the viewer. Big, bright, luminous eyes with reflective highlights.
- **Micro-Expression**: A mouth curved in joyful singing or a delightful smile with rosy cheeks. Never flat, neutral, or robotic expressions.
- **Lighting**: Soft, warm golden subsurface scattering (rim lighting, diyo glow, or sun flare) giving a premium 3D Pixar/Disney feel.

### Rule 2: High-Voltage Contrast (The Dark/Light Mode Pop)
- YouTube's feed is pure white (light mode) or near-black (dark mode).
- To aggressively pop off the screen:
  - **Backdrop**: Deep saturated Night Blue (`#081028` or `#14234B`) or Twilight Violet (`#200B40`).
  - **Foreground Accent**: High-voltage Marigold Gold (`#FFD166`), Flame Orange (`#FF7814`), or Electric Saffron (`#F7A21B`).
  - **Color Temperature Dynamic**: Warm foreground character set against a deep, cool background.

### Rule 3: The "3-Word Punchy Hook" (120px Phone Test)
- **Strict Limit**: Maximum **2 to 3 words** in Devanagari. Never put full sentences or lyrics.
- **Typography**: Windows **Nirmala UI Bold** set with complex text shaping (`libass`). AI image models must NEVER draw text.
- **Scale**: 110pt to 140pt font size.
- **Layering**:
  - Primary fill: Pure White (`#FFFFFF`) or Diyo Gold (`#FFD166`).
  - Secondary contour: 10px to 14px thick Night-Blue outline (`#0B225E` or `#081028`).
  - Outer glow: Subtle 4px to 6px translucent drop shadow (`#80000000`).
- **Passes the 120px Phone Test**: Text must be instantly readable when zoomed down to 10% on a phone screen.

### Rule 4: The Saffron Curiosity Eyebrow / Badge
- Every thumbnail includes a rounded rectangular badge in the upper corner:
  - **"तिहार विशेष"** (Festival Special)
  - **"नयाँ बालगीत"** (New Kids Rhyme)
  - **"४K बालगीत"** (4K Ultra HD)
  - **"सहर यात्रा"** (Urban Discovery)
  - **"नाचौँ साथी"** (Dance Along)
- Style: Saffron Orange (`#F7A21B`) or Crimson Red (`#C8102E`) pill with crisp white text.

### Rule 5: The Bottom-Right 25% Exclusion Zone
- YouTube automatically overlays the video duration stamp (e.g. `[ 5:15 ]`) in the bottom-right corner.
- **STRICT PROHIBITION**:
  - The bottom-right quadrant `(X > 75%, Y > 75%)` must have **zero text, zero logos, and zero character faces**.
  - All critical visual information must stay in the left 70% or upper 70% of the frame.

### Rule 6: Mandatory 2-Hypothesis A/B Testing Standard
Every project must produce **two distinct creative variations** to deploy into YouTube Studio's "Test & Compare":
1. **Hypothesis A (Emotion & Character Connection)**:
   - Tight framing: Close-up of lead character looking at the viewer with an emotional focal prop (diyo, flower, telescope, book).
   - Tone: Warm, sweet, educational, family-centered.
   - Text: Emotional hook (e.g., *"झिलिमिली भैलो!"*, *"हाम्रो सहर!"*, *"छमछम छठ!"*).
2. **Hypothesis B (High-Action & Celebration Drop)**:
   - Dynamic framing: Mid/group action shot with musical instruments (madal, drums, guitar, skateboard, e-bus).
   - Tone: Energetic, bouncy, high-tempo dance party.
   - Text: High-voltage action hook (e.g., *"भैलो आयो!"*, *"सहर आयो!"*, *"नाचौँ साथी!"*).

### Rule 7: Dual Format Enforcement (16:9 + 9:16 Vertical)
- **16:9 Landscape (1280 × 720)**: YouTube Main Video, Facebook Watch, Website Embeds.
- **9:16 Vertical (1080 × 1920)**: TikTok Studio, Instagram Reels, Facebook Reels, YouTube Shorts.
  - Keeps all text and character faces strictly between `Y = 350px` and `Y = 1500px` to avoid TikTok's bottom caption overlay and right-side social action icons (like/comment/share).

## 3. Standard Thumbnail File Naming Architecture

Inside each project directory `D:\claude_project\nepalirhymehub\<song_name>\out\`:
```
out/
├── <song_name>-thumb-A.jpg           # 16:9 Landscape Emotion Variant (YouTube Primary)
├── <song_name>-thumb-B.jpg           # 16:9 Landscape Action Variant (YouTube A/B Test)
├── <song_name>-vertical-thumb-A.jpg  # 9:16 Vertical Cover Emotion (TikTok & Reels)
└── <song_name>-vertical-thumb-B.jpg  # 9:16 Vertical Cover Action (TikTok & Reels A/B)
```
